# Contenido reutilizable desde el workspace de búsqueda

El repositorio privado de trabajo contiene material que puede convertirse en contenido público después de generalizarlo y revisar privacidad.

No debe copiarse literalmente.

## Material reutilizable

| Material actual | Página pública potencial | Qué conservar |
| --- | --- | --- |
| `content/context/job-sources.md` + `content/sources/` | Fuentes | taxonomía de fuentes, criterios de búsqueda, alertas, diferencia entre fuente y estado |
| `content/context/role-search-terms.md` | Búsquedas y palabras clave | familias de títulos, sinónimos, filtros, estrategia de queries |
| `content/context/company-eval-criteria.md` | Evalúa la empresa | criterios, señales positivas/negativas, preguntas |
| `content/context/opportunity-workflow.md` | Triage + Tracking | separación entre discovery, triage, preparación y aplicación; estados; deduplicación |
| `content/context/resume-content-guidelines.md` | Prepara tus materiales | impacto, evidencia, tailoring, no inventar experiencia |
| `content/context/market-insights.md` | Contexto de mercado | sólo aprendizajes generalizables y fechados |
| `content/application-forms/` | Prepara la aplicación | patrones de formularios, no respuestas personales |
| `content/interactions/` | Entrevistas / feedback | estructura de notas y aprendizaje, nunca conversaciones privadas |

## Qué no publicar directamente

- preferencias personales;
- salarios mínimos/targets de una persona;
- nombres de contactos;
- notas de entrevistas individuales;
- decisiones privadas sobre empresas;
- evaluaciones no verificadas;
- documentos de aplicación;
- cualquier dato que identifique una búsqueda particular.

## Proceso de extracción

1. Identificar un patrón probado en el workspace privado.
2. Separar regla general de dato personal.
3. Reescribir en español y para la audiencia México-first.
4. Verificar enlaces, nombres y datos que puedan haber cambiado.
5. Publicar inicialmente como `candidate`.
6. Revisar editorialmente antes de marcarlo como `reviewed`.

El workspace privado funciona como laboratorio; el website publica sólo el aprendizaje generalizable.
